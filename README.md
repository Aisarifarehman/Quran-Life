# Quran Life — Complete Quran Knowledge Explorer

Phase 2 — All 114 Surahs with Deep Knowledge, Kids Corner, Bookmarks, 48+ Languages

## Deploy to Vercel (FREE — 10 minutes)

### Step 1: Create GitHub account
Go to github.com → Sign up (free)

### Step 2: Create new repository
- Click the + button → New repository
- Name it: quran-life
- Set to Public
- Click Create repository

### Step 3: Upload these files
- Click "uploading an existing file"
- Drag and drop ALL files from this folder
- Click "Commit changes"

### Step 4: Deploy on Vercel
- Go to vercel.com → Sign up with GitHub (free)
- Click "New Project"
- Select your quran-life repository
- Click Deploy
- Wait 2 minutes
- Your app is LIVE at: quran-life.vercel.app

## Deploy to Netlify (Alternative — also FREE)

### Step 1: Go to netlify.com
### Step 2: Sign up free
### Step 3: Drag and drop the DIST folder
Run: npm run build
Then drag the /dist folder to Netlify
Done — live in 1 minute

## Run locally
npm install
npm run dev
Open: http://localhost:5173
